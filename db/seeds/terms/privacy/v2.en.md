## 1. General Provisions

SigLens is a free web service that provides technical analysis of the US stock market. The operator has designed the Service so that non-members can use all core features without restriction, and membership registration is optional. Members receive additional tier-based benefits, and in that process the minimum amount of identifiable information is collected.

This Privacy Policy applies to the web service (hereinafter the "Service") provided by the operator, and explains the information collected from non-members and members respectively and how it is processed.

## 2. Items of Personal Information Collected and Collection Methods

For **non-members**, the operator does not directly collect personal information such as name, email address, or phone number for the purpose of identifying users. However, the following information is automatically generated and collected for service operation and security purposes.

- Access logs: IP address, requested URL, HTTP status code, User-Agent, access date and time
- User environment settings stored in cookies and local storage (chart settings, selected technical indicators, etc.)
- If a user voluntarily uses the error report feature, the email address and inquiry content the user voluntarily provides
- AI question rate limiting: the IP address is converted into a SHA-256 hash in a form from which the original IP cannot be recovered, and is stored. It is automatically deleted after 24 hours and is not combined with other personal information.
- Access statistics (visitor count aggregation): a pseudonymized identifier created by combining the IP address and User-Agent and converting them into a SHA-256 hash, together with the access date, is stored. The original IP address is not stored, and it is not combined with other personal information. It is used only to determine the scale of service users (daily and monthly active users).

If a user chooses to register as a **member**, the following information is additionally collected to identify and authenticate the member.

- Email address (required)
- Password: the plaintext password is not stored; it is retained only in bcrypt hash form.
- Display name (optional)
- If social login is used, the OAuth provider's account identifier (provider account id) and profile image URL (optional)
- Authentication session token: stored in an HttpOnly cookie and used by the server to verify session expiration.
- Membership tier: one of free, member, or pro

Collection method: non-member information is automatically collected when a user accesses and uses the Service, and member information is either entered directly by the member during the sign-up, login, or social login process, or received from the OAuth provider based on the member's own consent.

## 3. Purpose of Collecting and Using Personal Information

The operator uses the collected information only for the following purposes, and does not use it for any other purpose.

- Providing and operating the Service: retrieving chart data, providing AI technical analysis results
- Member identification and authentication, and providing features according to membership tier
- Improving service quality: analyzing access statistics, tracking and reproducing errors
- Security and prevention of fraudulent use: detecting and blocking abnormal access, preventing account theft
- Responding to user inquiries and handling error reports

## 4. Retention and Use Period of Personal Information

The operator retains the collected information for the following periods and then destroys it without delay.

- Access logs: up to 3 months from the date of collection (for service stability and incident response purposes)
- Access statistics (visitor count aggregation): up to 400 days from the date of collection (for the purpose of comparing user trends against the same month of the previous year)
- Email addresses and inquiry content related to error reports: 1 year after processing is completed
- Cookies and local storage: until the user directly deletes them through browser settings
- Member information (email, password hash, display name, OAuth connection information, tier): destroyed without delay upon membership withdrawal. However, if retention is required under applicable law, it is retained for the period required by that law.
- Authentication session: up to 30 days from the date of issuance, or immediately discarded upon logout or session expiration

If retention is required under applicable law, the information is retained for the period prescribed by that law.

## 5. Provision of Personal Information to Third Parties

In principle, the operator does not provide users' personal information to outside parties. However, it may be provided in the following exceptional cases.

- Where the user has given prior consent
- Where required by law, or where a request is made by an investigative agency in accordance with the procedures and methods prescribed by law for investigative purposes

## 6. Outsourcing of Personal Information Processing and Overseas Transfer

The operator uses external infrastructure and API services to operate the Service. Personal information is transferred to some of these providers, while only service parameters that do not contain personal information are transmitted to the rest.

Personal Information Processing Outsourcing and Overseas Transfer Providers

- **Amazon Web Services, Inc.** (United States): web service hosting and computing — access information such as IP addresses arising from access to the Service is processed.
- **Cloudflare, Inc.** (United States): CDN and security (WAF) — access information such as IP addresses arising from access to the Service is processed.
- **Neon, Inc.** (United States): storage of member account, session, and tier information, and the pseudonymized identifier for visitor count aggregation, in a PostgreSQL database
- **Upstash, Inc.** (United States): AI question rate limiting (Redis) — a pseudonymized identifier created by hashing the IP address with SHA-256 is stored and automatically deleted after 24 hours.
- **Google LLC** (United States): outsourced OAuth authentication when a user chooses social login with a Google account — email and profile information is processed.
- **Kakao Corp.** (Republic of Korea): outsourced OAuth authentication when a user chooses social login with a Kakao account — email and profile information is processed.

The operator confirms each provider's privacy policy and imposes contractual obligations to ensure that the above providers do not use the information for purposes other than providing the Service.

External API Integrations (No Transfer of Personal Information)

Only service request data such as stock tickers and analysis parameters is transmitted to the providers below, and no personal information capable of identifying a user is included.

- **Financial Modeling Prep** (United States): retrieval of stock prices, financial statements, and company information
- **Yahoo Finance** (United States): retrieval of domestic (KRX) stock prices and chart data
- **NAVER Corp.** (Republic of Korea): domestic stock news search
- **한국 공공데이터포털 (Korea Public Data Portal)** (Republic of Korea): retrieval of KRX-listed stock information
- **Anthropic, PBC** (United States): generation of AI-based analysis and chat responses (Claude API)
- **Google LLC** (United States): generation of AI-based analysis and chat responses (Gemini API)
- **OpenAI Inc** (United States): generation of AI-based analysis and chat responses (ChatGPT API)
- **DeepSeek** (China): generation of AI-based analysis and chat responses (DeepSeek API)

## 7. Cookies and Local Storage

For user convenience, the operator uses browser cookies and local storage. Cookies and local storage store service environment settings such as chart settings, selected technical indicators, and analysis panel status.

If a member is logged in, the operator additionally uses the following security cookie to identify the authentication session.

- **siglens_session**: the authentication session token. HttpOnly, SameSite=Lax, and in the production environment the Secure flag is applied; the maximum expiration period is 30 days. It cannot be accessed via JavaScript.

Users may refuse cookie storage or delete stored data at any time through their browser settings. Deleting the authentication cookie automatically logs the user out, and refusing storage of other cookies may restrict the use of some service features.

## 8. User Rights and How to Exercise Them

Under the Personal Information Protection Act (개인정보 보호법), users have the right to request access, correction or deletion, and suspension of processing of their own personal information handled by the operator.

For non-members, because the collection of personally identifiable information is minimized, there may be no information subject to the exercise of this right if no separate personal information has been stored.

Members may withdraw their membership at any time after logging in, directly on the [Account Settings → Delete Account](/account/delete) page. Upon withdrawal, all member information (email, password hash, display name, OAuth connection information, tier) and all active sessions are immediately and permanently destroyed. However, if retention is required under applicable law, the information is retained only for the period required.

Even for members who signed up via social login (Google or Kakao), the app access permission registered with the external provider account is automatically revoked upon withdrawal, and the OAuth connection information held by the operator is also destroyed at the same time.

If a user wishes to view or delete the inquiry content they provided through an error report, they may make the same request using the same contact information.

## 9. Measures to Ensure the Security of Personal Information

The operator takes the following measures to safely process users' information.

- Applying HTTPS (TLS) encryption to all communication channels
- Managing external API keys and confidential information separately as environment variables
- Regularly reviewing access records and blocking abnormal access
- Minimizing server access privileges and conducting regular inspections
