## Round 3 — single finding

**recommended** — `entities/ticker/lib/assetClassification.ts:155-173` `isFundShapedName`
(added in round 2 as the SPCX safety net) classifies any symbol whose `name` last token is
`ETF|FUND|TRUST|ETN|INDEX` as `etf`. All 8 `buildAssetAboutNode` call sites pass
`assetInfo.koreanName ?? assetInfo.name`, so the *English* naming convention it documents only
holds pre-translation. Two consequences:
- Regression: a never-translated US company named `… Trust` (REITs — `Postal Realty Trust`,
  `Vornado Realty Trust`) loses its `Corporation` `about` node on the ISR-frozen first render.
  Pre-round-2 that returned `'stock'`.
- The guard stops guarding: once `translateCompanyNames` writes a Korean name, `classifyAsset`
  sees Korean and returns `'stock'` again — the SPCX recurrence the comment claims to prevent.
`buildPopularEntries` (the other `classifyAsset` caller) is unaffected — it passes
`CURATED_KOREAN_NAMES`, and only SPY/QQQ end in `ETF` there, both already in `KNOWN_ETF_TICKERS`.

## Non-findings — verified and deliberately NOT reported (don't re-raise)

- `currencyForSymbol(s) === 'KRW' ? '₩' : '$'` duplicated 4× (`PortfolioChip:79`,
  `PositionStatusSummary:70`, `positionBuildingNotes:50`, `priceFormat.formatSignedAmount:158`).
  Pure duplication, identical behaviour, no constructible failure today (a 4th non-USD/KRW
  profile would be needed). Deliberately withheld per "state the concrete failure".
- `formatSignedAmount` uses `en-US` locale for KRW while `numberFormat.ts` warns against it —
  harmless because it is *not* compact notation (grouping is identical to ko-KR).

  data.go.kr `getItemInfo` feed is stock-only → those rows become perpetual delist candidates.
  Could not verify the feed's ETF coverage without a live call; guard only degrades (skips
  delisting), never corrupts. Not reported.
- `.env.example:17` says translation "runs on DEEPSEEK_API_KEY (above)" but line 14 is
  `DEEPSEEK_CHAT_API_KEY` and `DEEPSEEK_API_KEY` is at line 84 (below). `check-env.sh` auto-collects

- `trimTrailingZeros` producing `₩74500` without grouping — deliberate (crypto sub-cent safety).
